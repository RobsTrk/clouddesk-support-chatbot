# Dashboard troubleshooting
Category: technical
Intent: technical_issue

## Steps
1. Refresh CloudDesk in a private browser window.
2. Disable browser extensions that modify page content.
3. Check whether the issue affects one workspace or multiple team members.
4. Record the page, error message, approximate time, and browser version.

## Escalation conditions
Escalate after the steps fail, when multiple users are affected, or when there is a reproducible error message.
