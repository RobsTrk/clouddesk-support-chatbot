# CloudDesk product features
Category: product
Intent: general_question, feature_request

## Overview
CloudDesk is a fictional SaaS platform for customer support teams. Its core features are ticket management, shared team inboxes, support automation, analytics, third-party integrations, and API access.

## Feature summary
- **Ticket management**: track, tag, and assign customer support tickets to the right team member.
- **Team inboxes**: shared inboxes so multiple agents can handle the same queue without duplicate replies.
- **Support automation**: routing and canned-response rules that reduce repetitive manual work.
- **Analytics**: reporting on ticket volume, response time, and resolution rate.
- **Integrations**: connections to tools such as Slack and Google Workspace (see the integrations articles).
- **API access**: programmatic access to tickets and workspace data for custom workflows.

## Restrictions
Workspace administrators manage members, billing, integrations, and API settings; team members work with tickets and shared inboxes according to their assigned permissions. Nova cannot enable a capability that is not included in the current subscription plan - see subscriptions/plans.md for upgrade options.

## Escalation conditions
Escalate a request for a capability that does not appear in this feature summary - it may be a genuine feature request rather than something CloudDesk already supports.
